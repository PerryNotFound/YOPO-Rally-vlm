# 系统概述

## 功能定位

YOPO-Rally 是一个面向越野地形的单阶段规划器，基于模仿学习，支持从仿真环境（YOPO-Sim）到实体机器人的零样本迁移（Sim-to-Real）。规划器以深度图和车辆状态为输入，直接输出多条候选轨迹及代价评分，由 MPC 局部规划器跟踪最优轨迹。

## 整体架构

```
Unity 仿真 / 实体机器人
    │
    ▼
深度图（OAK-D / Unity）+ 里程计（T265 / Unity）+ 目标点
    │
    ▼
yopo_node（YOPO 推理，10 Hz）
  ├─ 输入：单帧深度图 + 当前速度 + 目标向量
  └─ 输出：5 条候选轨迹 + 代价
    │
    ▼
mpc_node（MPC 局部跟踪，20 Hz）
  └─ 输出：/cmd_vel → 机器人底盘
```

## 网络输入输出

| 项目 | 说明 |
|------|------|
| 深度图输入 | 单帧深度图，形状 1×32×160，单位 m |
| 状态输入 | 4 通道：`[vx, vy, goal_x, goal_y]`，均归一化至 [-1, 1] |
| 轨迹输出 | 5 条候选，各含位置极坐标 `[pe_n, pe_θ]` 与速度 `[ve_x, ve_y]`（归一化） |
| 代价输出 | 5 个候选各自的代价预测，归一化至 [0, 1] |

## 训练数据格式

训练数据以场景（Scene）为单位组织，存放在 YOPO-Sim 的 `TrainingData/` 目录下：

```
TrainingData/
  Scene_0/
    terrain.ply, tree.ply   # 地形与植被点云
    Textures/map*.tif       # CloudCompare 输出的 GeoTIFF 代价图
    data.toml               # 原始帧数据（图像路径、位置、速度）
    data_opt.toml           # 优化后的专家轨迹标签（5 条候选及各自代价）
  Scene_1/
    ...
```

代价图以 GeoTIFF 格式存储，栅格分辨率 0.3 m，含倾斜度（DIP）和粗糙度（Roughness）两个波段，融合后生成 [0, 1] 范围的地形通行代价。
