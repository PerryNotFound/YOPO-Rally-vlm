# 数据训练流水线

从仿真器录制原始数据到训练出模型，共分以下几步：

```
Step 1  在 YOPO-Sim 中录制数据
  └─► Scene_i/data.toml + 深度图 + terrain.ply + tree.ply

Step 2  CloudCompare 点云处理
  └─► Textures/map*.tif（GeoTIFF 代价图）

Step 3  生成专家轨迹标签
  └─► Scene_i/data_opt.toml

Step 4  训练网络
  └─► models/<name>.pth

Step 5  评估
  └─► 各损失分量统计
```

---

## 快速启动

以下为从零到完成训练的最简操作流程，适合首次上手或快速复现。

### 前置条件

| 依赖项 | 说明 |
|--------|------|
| YOPO-Sim | 已完成仿真器安装，参见 [02-安装与环境.md](02-安装与环境.md) |
| CloudCompare 2.13+ | 用于点云处理，需加入系统 PATH |
| Python 依赖 | `uv sync` |

### 一、配置路径

编辑 `src/diablo_project/configs.py`，按实际路径修改以下三个变量：

```python
# YOPO-Sim 安装目录，TrainingData/ 和 TestingData/ 均在此下
YOPO_SIM_Path = "/path/to/YOPO-Sim"

# 训练权重输出目录
trained_model_folder = "models/temp"

# 推理时加载的模型路径（评估与部署使用）
load_model_path = "models/yopo_net.pth"
```

### 二、在仿真器中录制数据

1. 打开 YOPO-Sim，切换到场景：`Assets/Scenes/DataGenerationScene`
2. 调整场景参数（地形类型、障碍物密度等）
3. 点击 **Generate Data** 开始录制
4. 录制完成后，`$YOPO_SIM_Path/TrainingData/` 下会生成若干 `Scene_i/` 文件夹

### 三、生成专家轨迹标签

```bash
# 在项目根目录下执行
python src/diablo_project/generate_data.py
```

该脚本自动完成 CloudCompare 点云处理（Step 2）与轨迹优化标签生成（Step 3），耗时取决于场景数量，多场景时建议开启多进程（默认已开启）。

### 四、训练模型

```bash
python src/diablo_project/train_network.py
```

训练过程通过 TensorBoard 记录，实时查看损失曲线：

```bash
tensorboard --logdir models/temp
```

训练完成后，权重文件保存至 `trained_model_folder` 目录（默认 `models/temp/`）。

### 五、评估模型

```bash
python src/diablo_project/eval_network.py
```

输出位置、速度、代价各分量的损失统计，用于对比不同训练配置的效果。

> **提示**：完成训练后，将生成的 `.pth` 文件路径更新到 `configs.py` 的 `load_model_path`，即可在仿真推理（[03-仿真推理.md](03-仿真推理.md)）或实车部署（[05-实车部署.md](05-实车部署.md)）中使用新模型。

## Step 1：录制数据

在 YOPO-Sim 中切换到数据采集场景（`Assets\Scenes\DataGenerationScene`），调整参数后点击 **Generate Data** 开始录制。录制完成后，仿真器的 `TrainingData/` 目录下会生成若干 `Scene_i/` 文件夹，每个文件夹包含：

- `data.toml`：帧序列，记录时间戳、机器人位置/速度、目标位置及对应的深度图文件名。
- 深度图文件：单通道浮点格式（16UC1 或 32FC1），尺寸 160×32。
- `terrain.ply`、`tree.ply`：地形与植被点云，用于下一步处理。

---

## Step 2：CloudCompare 点云处理

脚本 `src/diablo_project/generate_data.py` 内部会自动调用 CloudCompare CLI，将 `terrain.ply` 和 `tree.ply` 合并并进行地形类型分析（TTA）：

1. 计算法线，提取倾斜度（DIP）和粗糙度（Roughness）特征。
2. 将结果栅格化为 GeoTIFF 文件（`Textures/map*.tif`），分辨率 0.3 m。

代价图融合两个波段：倾斜度超过 30° 或粗糙度超过 0.1 的区域被视为高代价，同时叠加符号距离场（SDF）以进行障碍物膨胀，最终代价范围 [0, 1]。

> 若需单独运行此步骤，可通过 CloudCompare 2.13+ 的 GUI 或命令行手动处理点云。

---

## Step 3：生成专家轨迹标签

运行以下命令生成优化标签：

```bash
python src/diablo_project/generate_data.py
```

程序读取 `data.toml` 中的起点与目标点，以 CasADi（IPOPT 求解器）对每个起点生成多条候选 Hermite 曲线轨迹，并从 GeoTIFF 代价图中查询各轨迹的地形代价，结果写入 `data_opt.toml`。

每个数据点包含 5 条候选轨迹及各自的代价，5 个候选出口在扇形角度范围内均匀分布。生成完成后，在 `configs.py` 中设置的 `trained_model_folder` 目录下可找到中间缓存文件。

---

## Step 4：训练

修改 `src/diablo_project/configs.py` 中的路径变量后，运行：

```bash
python src/diablo_project/train_network.py
```

主要超参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `batch_size` | 64 | 批大小 |
| `epochs` | 20 | 训练轮数 |
| 学习率 | 1e-3 | AdamW 优化器 |
| 数据划分 | 90% / 10% | 训练集 / 验证集 |

损失函数为 MSE，分别对位置极坐标、速度和代价 5 个通道计算。训练过程通过 TensorBoard 记录，权重保存到 `trained_model_folder`。

---

## Step 5：评估

```bash
python src/diablo_project/eval_network.py
```

程序加载 TorchScript 格式的模型并在测试集上评估，输出各损失分量（位置范数、位置角度、速度、代价）的统计值，便于对比不同训练配置的效果。

---

## configs.py 关键变量

| 变量 | 说明 |
|------|------|
| `YOPO_SIM_Path` | YOPO-Sim 根目录，`TrainingData/`  和 `TestingData/` 均在此下 |
| `load_model_path` | 推理时加载的模型路径 |
| `trained_model_folder` | 训练权重的输出目录 |
| `tiff_file_prefix` | GeoTIFF 文件名前缀（默认 `map`） |
