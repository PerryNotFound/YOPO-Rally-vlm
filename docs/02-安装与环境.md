# 安装与环境配置

## 系统要求

- Ubuntu 22.04
- ROS2 Humble
- Python 3.10
- CUDA 12.4（可选，有 GPU 时使用）
- CloudCompare 2.13+（训练时用于点云处理）

推荐通过 Flathub 安装 CloudCompare，参见 [Flathub 页面](https://flathub.org/apps/org.cloudcompare.CloudCompare)。

## 安装步骤

### 1. 克隆仓库

```bash
git clone https://github.com/TJU-Aerial-Robotics/YOPO-Rally.git --recursive
```

### 2. 安装 uv（推荐）

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 3. 创建虚拟环境

虚拟环境需携带系统 site-packages，以访问 ROS2 的 Python 包：

```bash
SYSTEM_PYTHON_VERSION=$(python3 --version | awk '{print $2}' | cut -d. -f1-2)
uv python pin $SYSTEM_PYTHON_VERSION
uv venv --system-site-packages
```

也可以用 `python -m venv .venv --system-site-packages` 代替。

### 4. 安装 Python 依赖

```bash
uv sync
```

此命令会自动安装 PyTorch（cu124）、open3d、casadi 及 `diablo-python` 包本身的所有依赖。

### 5. 编译 ROS2 包

```bash
source .venv/bin/activate
colcon build
source install/setup.bash
```

> 注意：不要使用 `--symlink-install`，否则 ROS2 节点无法调用虚拟环境的 Python 解释器。

### 6. 放置模型文件

从 Release 下载预训练的 `.pth` 权重文件，放置到工程根目录的 `models/` 文件夹下，并在 `src/diablo_project/configs.py` 中将 `load_model_path` 指向对应文件。

## 每次启动前

每次新开终端均需执行以下两行：

```bash
source .venv/bin/activate
source install/setup.bash
```
